# Android CI (GitHub-Hosted Runners)

Generated by `android-ci init`.

## Configuration

- Android project path: `apps/mobile/android`
- Android application id: `com.naatproduction`
- Play deploy enabled: `true`
- Sentry enabled: `true`
- Runner type: **GitHub-hosted** (ubuntu-latest)

## Required GitHub Secrets

Add these secrets to your repository at:
`https://github.com/YOUR_USERNAME/YOUR_REPO/settings/secrets/actions`

### Required Secrets:

- `ANDROID_KEYSTORE_BASE64` - Base64 encoded keystore file
- `PLAY_STORE_JSON_BASE64` - Base64 encoded Play Store service account JSON
- `ANDROID_KEYSTORE_PASSWORD` - Keystore password
- `ANDROID_KEY_ALIAS` - Key alias
- `ANDROID_KEY_PASSWORD` - Key password
- \`SENTRY_AUTH_TOKEN\` - Sentry authentication token


## Encoding Your Secrets

Use the provided helper scripts in `scripts/` directory:

### Linux/macOS:
```bash
./scripts/encode-secrets.sh path/to/release.keystore path/to/play-store-key.json
```

### Windows (PowerShell):
```powershell
.\scripts\encode-secrets.ps1 path\to\release.keystore path\to\play-store-key.json
```

Copy the output and add it to your GitHub repository secrets.

## Optional GitHub Variables

You can override these via repository variables:

- `ANDROID_APPLICATION_ID` - Override the application ID
- \`PLAY_TRACK\` - Play Store track (default: alpha)
- \`SENTRY_ORG\` - Sentry organization
- \`SENTRY_PROJECT\` - Sentry project

✅ Fast builds (10-15 minutes)

✅ No VM setup required

✅ Secure secret handling via base64 encoding

## Triggering Builds

Go to: `https://github.com/YOUR_USERNAME/YOUR_REPO/actions`

1. Select "Android CI" workflow
2. Click "Run workflow"
3. Choose the app variant (development/preview/production)
4. Click "Run workflow"
